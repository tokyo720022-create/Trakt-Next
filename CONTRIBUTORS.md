## How to contribute

1. Open an issue to describe the bug or idea.
2. Keep to the structure in the README: screens in `views/`, logic in `js/core/` and `js/features/`, styles in `css/`.
3. Run `node tests/check-structure.js` and the unit tests in `tests/unit/` before sending a change.
4. Add yourself to the table above in the same change.
